🚀 Projeto Full Stack com React, Node.js e Prisma
Este sistema full stack foi desenvolvido com React no frontend e Node.js no backend. Utiliza o ORM Prisma para conexão com o banco de dados MongoDB hospedado na AWS. A API permite cadastrar, editar, excluir e listar usuários de forma eficiente e escalável.
![image](https://github.com/user-attachments/assets/16c7d6d8-9eae-4768-83d4-189c738504f0)

🛠️ Tecnologias utilizadas
Frontend: React, Axios, CORS

Backend: Node.js, Express, Prisma

Banco de dados: MongoDB (AWS)

📥 Instalação
🔹 Clonando o repositório
bash
git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio
🔹 Instalando dependências
Frontend (React):

bash
cd frontend
npm install axios
npm install cors
npm run dev
Backend (Node.js):

bash
cd backend
npm install prisma
npm install express
🚀 Executando o projeto
🔹 Rodando o Backend
bash
node server.js
ou com hot reload:

bash
node --watch server.js
🔹 Rodando o Frontend
bash
npm run dev
📌 Configuração do Banco de Dados
Este projeto utiliza Prisma para gerenciar a conexão com MongoDB AWS. Certifique-se de configurar corretamente as variáveis de ambiente no arquivo .env.
